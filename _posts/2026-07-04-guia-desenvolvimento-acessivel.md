## Leitores de tela

### NVDA

O NVDA é meu leitor de tela principal e um dos mais conhecidos pela comunidade de programadores cegos que usam Windows. Atualmente, para programas minimamente acessíveis, suas funcionalidades são suficientes para desempenhar um trabalho excelente.

Dentre as funções que mais destaco, estão:

- Alta compatibilidade com o Windows
- Personalização
- Plugins criados pela comunidade para resolver problemas específicos e adicionar funcionalidades

### VoiceOver

Apesar de saber que o VoiceOver possui uma acessibilidade excelente no sistema operacional macOS, ainda estou me adaptando ao ambiente Apple. Mesmo assim, pode ser um grande aliado para programadores que já estão habituados ao ecossistema da Apple.

## Ferramentas de desenvolvimento

Para programação, destaco as seguintes ferramentas que utilizo no meu dia a dia:

- Visual Studio
  - Descrição: IDE da Microsoft para desenvolvimento de aplicações e soluções diversas.
- Visual Studio Code
  - Descrição: Editor de código leve, amplamente utilizado e com grande suporte a extensões.
- Insomnia
  - Descrição: Ferramenta para testar e documentar APIs com interface simples e prática.
- Windows Terminal
  - Descrição: Terminal moderno e personalizável para o ambiente Windows.
- SQL Server Management Studio
  - Descrição: Ferramenta oficial da Microsoft para gerenciar bancos de dados SQL Server.
- Google Chrome
  - Descrição: Navegador com bom suporte a ferramentas de desenvolvimento e acessibilidade.
