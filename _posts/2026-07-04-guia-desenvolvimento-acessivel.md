## Leitores de tela

### NVDA

O NVDA é meu leitor de tela principal e um dos mais conhecidos pela comunidade de programadores cegos que usam Windows. Para programas minimamente acessíveis, ele costuma ser suficiente para realizar um trabalho muito produtivo.

Entre as funções que mais destaco estão:

- Alta compatibilidade com o Windows
- Personalização
- Plugins criados pela comunidade para resolver problemas específicos

## Ferramentas de desenvolvimento

Para programação, destaco as seguintes ferramentas que uso no dia a dia:

### Notepad++

O Notepad++ é um editor de texto e código leve, útil para abrir, editar e organizar arquivos de texto, scripts e pequenas anotações. Com o NVDA, ele funciona de forma excelente quando o usuário conhece os atalhos básicos e a navegação do editor. Sua interface simples facilita o uso diário, sobretudo para tarefas rápidas e edição de textos.

Atalhos úteis:

- Ctrl+N: cria um novo documento
- Ctrl+W: fecha o documento atual
- Ctrl+Shift+Seta para cima ou para baixo: move a linha para a direção desejada

### Ferramentas Google: Drive, Docs, Sheets e Tasks

As ferramentas do ecossistema Google funcionam bem com o leitor de tela. Por serem aplicações web, o início pode exigir um pouco de adaptação, mas a curva de aprendizado costuma ser rápida. A documentação oficial e os atalhos específicos ajudam bastante na rotina.

### Visual Studio Code

O Visual Studio Code é um editor de código leve, bastante popular e com suporte a extensões para diversas linguagens e fluxos de trabalho. Com o NVDA, ele costuma oferecer uma boa experiência, especialmente para quem trabalha com arquivos, painéis e terminal integrado.
Em especial, gosto de utilizar o vs code como centro de organização de anotações pessoais utilizando o mark down. Por ser rápido, acessível e com suporte a extensões, ele se torna uma ferramenta poderosa para manter o fluxo de estudos e desenvolvimento organizado, não só para programação mas para qualquer assunto.

Atalhos úteis:

- Ctrl+Shift+P ou F1: abre a paleta de comandos
- Ctrl+P: abre a busca rápida de arquivos
- F6: alterna entre os painéis abertos
- Ctrl+`: abre o terminal integrado
- Ctrl+Shift+E: abre o explorador de arquivos

### Insomnia

O Insomnia é uma ferramenta para testar, enviar e documentar requisições de APIs de forma prática. A experiência com o NVDA costuma ser satisfatória, embora alguns elementos da interface ainda possam ser menos claros. Mesmo assim, ele é uma opção útil para quem precisa trabalhar com APIs no dia a dia.

### Windows Terminal

O Windows Terminal é um terminal moderno e personalizável para o ambiente Windows, ideal para trabalhar com comandos, scripts e ferramentas de linha de comando. Com o NVDA, ele pode ser usado com produtividade, principalmente para quem já tem familiaridade com o prompt de comando. Para leitura dos resultados, é importante conhecer alguns comandos de revisão de texto do leitor de tela.

### Visual Studio

O Visual Studio é uma IDE da Microsoft voltada para o desenvolvimento de aplicações e soluções mais completas no ecossistema Windows. Em termos de acessibilidade, o NVDA ajuda na navegação do ambiente, mas a experiência depende da configuração e da adaptação do usuário à interface.

### SQL Server Management Studio

O SQL Server Management Studio é a ferramenta oficial da Microsoft para gerenciar bancos de dados SQL Server, executar consultas e administrar objetos do banco. Com o NVDA, ele pode ser usado, embora a acessibilidade seja mais limitada em comparação com ferramentas mais leves. Ainda assim, ele permanece uma opção robusta para administração de bancos em ambientes corporativos.

### Google Chrome

O Google Chrome é um navegador web amplamente utilizado para acessar aplicações, testar ambientes e usar ferramentas de desenvolvimento. Ele funciona bem com o NVDA e oferece uma navegação satisfatória em páginas, abas e ferramentas do desenvolvedor. A escolha entre navegadores costuma ser mais uma questão de preferência pessoal do que de limitação técnica.
