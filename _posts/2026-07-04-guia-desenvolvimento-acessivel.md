## Leitores de tela

### NVDA

O NVDA é meu leitor de tela principal e um dos mais conhecidos pela comunidade de programadores cegos que usam Windows. Atualmente, para programas minimamente acessíveis, suas funcionalidades são suficientes para desempenhar um trabalho excelente.

Dentre as funções que mais destaco, estão:

- Alta compatibilidade com o Windows
- Personalização
- Plugins criados pela comunidade para resolver problemas específicos e adicionar funcionalidades

### VoiceOver

Apesar de saber que o VoiceOver possui uma acessibilidade excelente no sistema operacional macOS, ainda estou me adaptando ao ambiente Apple. Mesmo assim, pode ser um grande aliado para programadores que já estão habituados ao ecossistema da Apple.

## Ferramentas de desenvolvimento

Para programação, destaco as seguintes ferramentas que utilizo no meu dia a dia:

### Notepad++

O Notepad++ é um editor de texto e código leve, muito útil para abrir, editar e organizar arquivos de texto, scripts e pequenas anotações de desenvolvimento. Em relação à acessibilidade, ele pode ser usado com o NVDA de forma satisfatória, especialmente quando o usuário conhece os atalhos e a navegação pelo editor.
Por ser um editor de texto simples, não é necessário dominar funções complexas do aplicativo ou do leitor de tela para pleno uso. Destaco o uso desse aplicativo como editor de texto padrão por salvar os documentos de forma automática e por todas as funções de formatação e edição de linhas como: ordenação, movimentação e possibilidade de uso de plugins.

Atalhos úteis:

- ctrl + T: cria um novo documento
- ctrl + W: fecha o documento atual.
- ctrl + shift + ↕: movimenta a linha para a direção desejada.

### Visual Studio

O Visual Studio é uma IDE da Microsoft voltada para o desenvolvimento de aplicações, soluções e projetos mais completos no ecossistema Windows. Em termos de acessibilidade, o NVDA pode ajudar na navegação pelo ambiente da IDE, embora a experiência dependa de como as telas e os recursos estão configurados.
Nesse programa, o NVDA sempre estará no modo de foco e, portanto, os atalhos dependem exclusivamente do que está configurado no Visual Studio, que pode levar um tempo maior de adaptação. 

### Visual Studio Code

O Visual Studio Code é um editor de código leve, bastante popular e com suporte a extensões para diversas linguagens e fluxos de trabalho. Com o NVDA, ele costuma oferecer uma boa experiência de uso, especialmente para quem trabalha com código e precisa navegar entre arquivos, painéis e terminal.
Dentre as IDEs (interfaces de desenvolvimento), o vs code tem a fama de ser um dos mais acessívieis para uso com o leitor de tela.

### Insomnia
O Insomnia é uma ferramenta usada para testar, enviar e documentar requisições de APIs de forma prática. Em relação à acessibilidade, o NVDA pode ser útil para navegar pela interface, desde que o usuário esteja acostumado com os comandos do leitor de tela.

### Windows Terminal
O Windows Terminal é um terminal moderno e personalizável para o ambiente Windows, ideal para trabalhar com comandos, scripts e ferramentas de linha de comando. Com o NVDA, ele pode ser usado de forma produtiva, principalmente para quem precisa interagir com prompts e saídas de texto.

### SQL Server Management Studio
O SQL Server Management Studio é a ferramenta oficial da Microsoft para gerenciar bancos de dados SQL Server, executar consultas e administrar objetos do banco. No uso com o NVDA, a experiência depende da familiaridade com a interface e da forma como os elementos são acessados.

### Google Chrome
O Google Chrome é um navegador web amplamente utilizado para acessar aplicações, testar ambientes e usar ferramentas de desenvolvimento. Em relação à acessibilidade, ele funciona bem com o NVDA e oferece uma boa navegação para quem precisa explorar páginas, abas e ferramentas do desenvolvedor.
